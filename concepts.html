NLP Concepts

Nine building blocks behind the pipeline, each explained the same way: definition, purpose, mechanism, a worked example, and where it shows up in practice. Use the search box above to filter.

Question Answering
Definition
An NLP task where a system returns a direct answer to a natural-language question instead of a list of documents.
Purpose
Collapses the gap between asking and knowing — the user gets the answer, not the homework of finding it.
How it works
Combines retrieval (finding relevant text) with either span extraction or answer generation.
Example
Q: "Who founded Infosys?" → A: "N. R. Narayana Murthy."
Advantages
Fast, precise, reduces reading effort.
Limitations
Only as good as its source documents and retrieval quality.
Applications
Search engines, chatbots, voice assistants, helpdesks.
Tokenization
Definition
Splitting raw text into smaller units — words, subwords, or characters — that a model can process.
Purpose
Neural networks operate on numbers, not text; tokenization is the first translation step.
How it works
A tokenizer applies rules or a learned vocabulary (e.g. Byte-Pair Encoding) to break text into tokens, then maps each token to an ID.
Example
"Gandhinagar" → ["Gandhi", "##nagar"] in a subword tokenizer.
Advantages
Handles rare and compound words gracefully via subwords.
Limitations
Script-specific quirks (like Gujarati conjuncts) need tokenizers trained on that script, not borrowed from English.
Applications
Every step downstream: embeddings, search, generation.
Embeddings
Definition
Dense numerical vectors that represent the meaning of a word, sentence, or document in a continuous space.
Purpose
Let a computer compare meaning, not just matching characters — 'doctor' and 'physician' land near each other.
How it works
A trained encoder model maps text to a fixed-length vector; semantic similarity becomes distance in that vector space.
Example
A 384-dimension vector representing the sentence "The capital of Gujarat is Gandhinagar."
Advantages
Enables semantic (meaning-based) search rather than exact keyword matching.
Limitations
Quality depends entirely on training data; multilingual embeddings need multilingual training corpora.
Applications
Semantic search, clustering, recommendation, retrieval for QA.
Transformers
Definition
A neural network architecture built on self-attention, which lets every word in a sequence weigh every other word.
Purpose
Captures long-range context far better than earlier recurrent architectures, and trains in parallel.
How it works
Stacks of attention and feed-forward layers process an entire sequence at once, learning which words matter to which.
Example
BERT, GPT, and Llama are all transformer variants.
Advantages
State-of-the-art accuracy across nearly all NLP tasks.
Limitations
Computationally heavy; needs large data and compute to train from scratch.
Applications
Translation, summarization, question answering, code generation.
Retrieval
Definition
The process of finding the passages most relevant to a query from a large collection of documents.
Purpose
A language model can't read an entire library before answering — retrieval narrows that library to a few relevant pages.
How it works
A query is embedded, then compared against pre-embedded document chunks using a similarity metric like cosine distance.
Example
Given a 300-page textbook, retrieval surfaces the 3 paragraphs relevant to the question asked.
Advantages
Keeps answers grounded in real source material.
Limitations
Poor chunking or embedding choices can bury the right passage.
Applications
RAG pipelines, enterprise search, legal and medical document lookup.
RAG (Retrieval-Augmented Generation)
Definition
An architecture that retrieves relevant passages first, then feeds them to a language model to generate the final answer.
Purpose
Combines the factual grounding of retrieval with the fluency of generation.
How it works
Query → retrieve top-k chunks from a vector database → construct a prompt with those chunks → language model generates an answer.
Example
A PDF Q&A chatbot that answers questions strictly from an uploaded document.
Advantages
Reduces hallucination compared to a language model answering from memory alone.
Limitations
Still bounded by retrieval quality and context window size.
Applications
Document chatbots, customer support, internal knowledge assistants.
FAISS
Definition
Facebook AI Similarity Search — an open-source library for fast nearest-neighbour search over dense vectors.
Purpose
Makes it feasible to search millions of embeddings in milliseconds.
How it works
Indexes vectors using structures like inverted files or HNSW graphs to avoid brute-force comparison.
Example
Searching 100,000 embedded paragraphs for the 5 closest to a question vector.
Advantages
Extremely fast, scales to large corpora, runs locally.
Limitations
Approximate search trades a small amount of accuracy for speed at scale.
Applications
Vector databases, RAG pipelines, recommendation systems.
BERT
Definition
Bidirectional Encoder Representations from Transformers — a transformer model pretrained to understand context from both directions.
Purpose
Produces rich contextual representations of text, useful for classification, extraction, and embeddings.
How it works
Pretrained on masked-word prediction and next-sentence prediction over large text corpora, then fine-tuned for specific tasks.
Example
Fine-tuned BERT extracting the exact answer span from a passage for a given question.
Advantages
Strong general-purpose language understanding.
Limitations
English-centric by default; needs a multilingual variant for Gujarati.
Applications
Extractive QA, classification, named entity recognition.
Multilingual Models
Definition
Language models trained on text from many languages simultaneously, sharing a single vocabulary and parameter set.
Purpose
Let one model serve many languages, including lower-resource ones like Gujarati, without training from scratch for each.
How it works
Trained on multilingual corpora with a shared subword vocabulary, learning cross-lingual representations.
Example
mBERT and multilingual sentence-embedding models supporting Gujarati text.
Advantages
One pipeline serves multiple languages; cross-lingual transfer helps low-resource languages.
Limitations
Per-language performance is usually a notch below a model trained specifically for that language.
Applications
Bilingual and multilingual QA, cross-lingual search, translation.
