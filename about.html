Introduction

What is Question Answering?પ્રશ્ન-જવાબ એટલે શું?

Question Answering (QA) is the branch of Natural Language Processing concerned with automatically producing a precise answer to a question posed in natural language, rather than a ranked list of documents that might contain it. A QA system reads, searches, and reasons over a knowledge source — a PDF, a website, a database — and returns the specific span of text (or a freshly generated sentence) that answers the question.

Two families

How QA systems workકાર્યપદ્ધતિ

Extractive QA

Locates the exact span of text in a source document that answers the question. Fast, grounded, and hard to hallucinate — but limited to what is written verbatim.

Generative / Retrieval-Augmented QA

Retrieves the most relevant passages, then hands them to a language model that composes a fluent answer in its own words. More natural, but only as reliable as its retrieval step.

This project

Scope of this repositoryઆ પ્રોજેક્ટનો વ્યાપ

This repository documents a bilingual QA pipeline that accepts questions in either English or Gujarati, detects the language automatically, retrieves relevant passages using vector search, and returns an answer in the same script the question was asked in. It draws on retrieval-augmented generation (RAG), multilingual embeddings, and transformer-based language models — each explained on the Concepts page.
