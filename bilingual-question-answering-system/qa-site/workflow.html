An extra Unicode normalization step comes first — Gujarati text can arrive in visually identical but byte-different forms (combining marks vs. precomposed characters), and normalizing that before tokenization prevents silent retrieval failures.

Why the fork happens where it does

Language detection runs once, immediately after the question arrives, so every downstream component — tokenizer, embedding model, and the script used to render the final answer — can be chosen correctly for that language rather than guessed at each step.
